# 📄 Feira Currículo

Projeto desenvolvido em grupo pelo **3º D — Desenvolvimento de Sistemas**, durante as aulas do curso técnico.

## 🎯 Sobre o projeto

O **Feira Currículo** é um sistema que permite ao usuário cadastrar suas informações pessoais, formação acadêmica, experiências profissionais, habilidades e idiomas, gerando automaticamente um **currículo em PDF**.

## ⚙️ Funcionalidades

* Cadastro de informações pessoais
* Adição de foto pela galeria ou câmera
* Formação acadêmica
* Experiência profissional
* Habilidades e idiomas
* Geração do currículo em PDF

## 💻 Tecnologias

* HTML5
* CSS3
* JavaScript
